inno-creed

이노그리드 그룹웨어 아마란스(gw.innogrid.com)를 Claude와의 대화로 다루는 MCP 서버입니다.
회의실 예약, 메일, 결재, 일정, 게시판, 근태를 브라우저 없이 처리합니다.

최신 릴리즈 다운로드 설치 프로그램으로 설치하기 확장 프로그램 설치 방법 macOS 첫 실행 허용하기 GitHub 저장소 전체 설치 문서

지금 어떤 Claude를 쓰고 계신가요?

"Claude"라는 이름 하나로 불려도 실제로는 서로 다른 프로그램입니다. inno-creed는 여러분의 컴퓨터에서 직접 실행되는 프로그램이라, Claude가 그 컴퓨터와 어떻게 연결되는지에 따라 쓸 수 있는지 여부가 갈립니다.

설치 불가
웹버전
claude.ai · Desktop 앱의 Chat 탭

평소 채팅하는 그 화면입니다. 서버(클라우드)에서 실행되기 때문에 여러분 컴퓨터에 있는 inno-creed 프로그램을 알거나 실행할 방법이 없습니다.

조건부 가능
Cowork
Desktop 앱의 Cowork 탭

"이 일을 해줘"라고 맡기면 알아서 처리하는 에이전트 모드입니다. 컴퓨터에 설치된 Desktop 앱이 켜져 있으면 그 앱이 다리 역할을 해서, 웹브라우저·휴대폰의 Cowork 세션에서도 그대로 연결됩니다. Desktop 앱 자체가 꺼져 있으면 어디서 접속하든 안 됩니다.

가능
Code
Desktop 앱의 Code 탭

Claude Code를 데스크톱 앱 화면 안에 넣어놓은 것입니다. 개발자용으로 보이지만, 설치만 한 번 해두면 대화창은 CLI와 똑같이 쓸 수 있습니다.

가능
CLI
터미널의 claude 명령

터미널(명령창)에서 실행하는 버전입니다. Code 탭과 완전히 같은 프로그램이라 설정을 공유합니다.

Code와 CLI는 사실 같은 엔진입니다. 화면(데스크톱 창 vs 터미널)만 다를 뿐 Claude Code라는 같은 프로그램이라, 아래 방법대로 터미널에서 딱 한 번 등록하면 Desktop 앱의 Code 탭에서도 그대로 보입니다. 따로 두 번 설치할 필요가 없습니다.

환경별 설치 방법

아래에서 지금 쓰는 환경을 골라 따라 하세요. (전체 문제해결·상세 옵션은 설치 가이드 전문 참고)

CLI — 터미널에서 등록

가장 쉬운 방법: 명령을 몰라도 됩니다. Claude Code를 켜고 이 저장소 주소와 함께 설치를 부탁하세요.

https://github.com/zilhak/inno-creed
이 MCP 설치해줘

이렇게 입력하면 Claude가 알아서 내려받고 등록까지 해줍니다. 이어지는 안내를 그대로 따라가면 됩니다.

등록만으로는 끝이 아닙니다 — 확장 프로그램까지 올려야 로그인이 잡힙니다(모든 OS). Claude가 안내해 주지만, 브라우저를 직접 조작하는 단계라 사람이 해야 합니다: 확장 프로그램 설치 방법(그림 12단계). 다 됐는지는 inno-creed doctor의 [실제 인증 확인] ✅로 판단하세요 — 도구 목록이 보이는 것과 인증이 된 것은 별개입니다.
Claude에게 안 부탁하고 직접 설치하기
  1. 릴리즈 페이지에서 OS에 맞는 파일을 내려받고, macOS·Linux는 chmod +x inno-creed-*로 실행 권한을 줍니다.
  2. 등록합니다: 
    claude mcp add inno-creed --scope user -- /절대경로/inno-creed
# Windows는 경로 끝이 ...\inno-creed.exe
    ⚠️ --scope user를 빼먹으면 지금 등록한 폴더에서만 보입니다.
  3. 터미널을 새로 열면(또는 claude 재시작) 도구가 보입니다.
  4. 로그인 인증 연결 — Chrome/Edge 확장 프로그램이 필요합니다(모든 OS). 화면 그대로 따라가려면 확장 프로그램 설치 방법을 보세요.
    1. inno-creed-extension.zip을 받아 압축을 풀어둡니다(지우지 말고 그대로 둡니다 — 브라우저가 그 폴더를 계속 읽습니다).
    2. chrome://extensions(또는 edge://extensions)를 열고 개발자 모드를 켭니다 — Chrome은 화면 우측 상단, Edge는 좌측 하단에 있습니다.
    3. "압축해제된 확장 프로그램을 로드합니다"(Edge는 "압축 풀린 파일 로드")로 방금 그 폴더를 선택합니다. 그 다음 gw.innogrid.com에 로그인하면 연결됩니다.
    4. ⚠️ macOS에서는 Chrome을 쓰세요 — 맥은 Edge를 지원하지 않아, Edge에 올리면 에러 없이 조용히 연결되지 않습니다.
    5. ⚠️ 2·3번(등록·재시작)을 먼저 끝낸 뒤에 확장을 올리세요. 브라우저 연결 등록은 inno-creed가 한 번 실행될 때 자동으로 만들어지므로, 순서를 바꾸면 첫 연결이 빈손으로 끝납니다(그 경우 아마란스에서 다시 로그인하면 붙습니다).
    6. ⚠️ Edge를 새로 켤 때 "개발자 모드에서 확장 사용 해제" 경고가 뜨면 [확장 사용 해제]는 누르지 말고 [나중에]를 누르세요.

Code (Desktop 앱)

Code 탭은 터미널의 Claude Code를 창 안에 그대로 넣은 것이라, 다운로드조차 필요 없습니다. 이 채팅창에 저장소 주소와 함께 설치를 부탁하세요.

https://github.com/zilhak/inno-creed
이 MCP 설치해줘

Claude가 알아서 내려받고 등록까지 해줍니다. 이어지는 안내를 그대로 따라가면 됩니다. 끝나면 Desktop 앱을 완전히 종료했다가 다시 열어야 도구가 보입니다.

등록만으로는 끝이 아닙니다 — 확장 프로그램까지 올려야 로그인이 잡힙니다(모든 OS). 브라우저를 직접 조작하는 단계라 사람이 해야 합니다: 확장 프로그램 설치 방법(그림 12단계). 다 됐는지는 inno-creed doctor의 [실제 인증 확인] ✅로 판단하세요.
Claude에게 안 부탁하고 다른 방법으로 설치하기

GUI 인스톨러도 됩니다 — JSON을 직접 안 건드립니다.

  1. 릴리즈 페이지에서 inno-creed-installer-<OS>.zip을 받습니다. Windows ARM64는 inno-creed-installer-windows-aarch64.zip을 선택하세요.
  2. 압축을 통째로 풀고, 안에 있는 installer(Windows는 installer.exe)를 실행합니다 — 옆의 payload/ 폴더와 같은 자리에 둔 채로 실행해야 합니다.
  3. 미서명 배포판이라 뜨는 정상 경고를 한 번 넘겨야 합니다. Windows는 SmartScreen 경고에서 추가 정보 → 실행, macOS는 "열 수 없음"으로 아예 막히므로 macOS 첫 실행 허용하기를 따라가세요(최신 버전은 설치 도중 한 번 더 뜨지 않습니다).
  4. 여기까지가 어렵게 느껴지면 그림으로 보는 설치 방법을 그대로 따라가세요. 창이 안 뜨는 컴퓨터라면 글자 화면으로 설치하기가 있습니다.
  5. 화면 안내를 따라가면 설치와 확장 프로그램 연결까지 끝납니다. 확장 프로그램을 브라우저에 올리는 단계는 그림으로 보는 설치 방법을 따라가면 됩니다.

터미널 사용이 익숙하다면 CLI 탭의 명령을 그대로 써도 됩니다(Code와 CLI는 같은 프로그램이라 설정을 공유합니다) — 다만 터미널이 낯설다면 위 두 방법 중 하나를 쓰세요.

Cowork (Desktop 앱)

JSON을 직접 건드릴 필요 없이, GUI 인스톨러로 클릭 몇 번이면 끝납니다.

  1. 릴리즈 페이지에서 inno-creed-installer-<OS>.zip을 받습니다. Windows ARM64는 inno-creed-installer-windows-aarch64.zip을 선택하세요.
  2. 압축을 통째로 풀고, 안에 있는 installer(Windows는 installer.exe)를 실행합니다 — 옆의 payload/ 폴더와 같은 자리에 둔 채로 실행해야 합니다.
  3. 미서명 배포판이라 뜨는 정상 경고를 한 번 넘겨야 합니다. Windows는 SmartScreen 경고에서 추가 정보 → 실행, macOS는 "열 수 없음"으로 아예 막히므로 macOS 첫 실행 허용하기를 따라가세요(최신 버전은 설치 도중 한 번 더 뜨지 않습니다).
  4. 여기까지가 어렵게 느껴지면 그림으로 보는 설치 방법을 그대로 따라가세요. 창이 안 뜨는 컴퓨터라면 글자 화면으로 설치하기가 있습니다.
  5. 화면 안내를 따라가면 설치와 확장 프로그램 연결까지 끝납니다. 확장 프로그램을 브라우저에 올리는 단계는 그림으로 보는 설치 방법을 따라가면 됩니다.
  6. Desktop 앱을 완전히 종료(트레이 포함)했다가 다시 실행하면 Cowork·Chat 탭에서 바로 쓸 수 있습니다. (Code 탭은 설정 파일이 따로라 위 Code 탭의 방법으로 한 번 더 등록해야 합니다.)
  7. 인스톨러 마지막 화면의 인증 확인 결과가 ✅인지 보세요. ❌라면 확장 프로그램을 아직 브라우저에 올리지 않았거나 아마란스에 로그인되어 있지 않은 것입니다.
웹브라우저나 휴대폰 앱으로 켠 Cowork 세션에서도 됩니다 — 단, 컴퓨터에 설치된 Desktop 앱이 실행 중이어야 합니다. Desktop 앱이 다리 역할을 해서 로컬 도구를 원격 세션으로 연결해주기 때문입니다(도구 이름 앞에 remote-devices가 붙어서 나타납니다). Desktop 앱 자체를 꺼두면 어디서 접속하든 안 됩니다.
인스톨러 없이 직접 설치하기

앱 안의 커넥터(Connectors) 설정에 직접 추가하거나, 아래 설정 파일을 편집합니다.

환경claude_desktop_config.json 위치
macOS~/Library/Application Support/Claude/
Windows (일반 설치)%APPDATA%\Claude\
Windows (Microsoft Store)%LOCALAPPDATA%\Packages\Claude_<패키지ID>\LocalCache\Roaming\Claude\
{
  "mcpServers": {
    "inno-creed": {
      "command": "/절대경로/inno-creed"
    }
  }
}

저장 후 Desktop 앱을 완전히 종료(트레이 포함)했다가 다시 실행하세요. 실행 파일은 릴리즈 페이지에서 받으면 됩니다. 로그인 인증 연결(확장 프로그램, 모든 OS 필요)은 확장 프로그램 설치 방법(그림 안내) 또는 가이드 4번 참고.

웹버전 — 설치할 수 없습니다

claude.ai나 Desktop 앱의 Chat 탭은 클라우드에서 돌아가는 대화 화면이라, 여러분 컴퓨터에 설치한 프로그램과 연결할 방법 자체가 없습니다. 아마란스 업무를 대화로 처리하려면 위의 Cowork · Code · CLI 중 하나를 이용해 주세요.

가장 진입장벽이 낮은 건 Cowork입니다 — 터미널을 열 필요 없이 Desktop 앱 화면에서 설정을 마칠 수 있습니다.

더 자세한 문제 해결(크레덴셜 인식 안 될 때 등)은 설치 가이드 전문, 전체 기능 목록은 README를 참고하세요.
